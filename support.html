# FinalTurn Support Thank you for using FinalTurn. If you have questions, encounter a bug, or would like to suggest a feature, please contact: Email: finalturnapp@gmail.com ### Frequently Asked Questions How do I create a deck? Open the Decks tab and tap the + button. How do I import a decklist? Use the Import option and paste a supported decklist format. How do I restore Premium purchases? Open the Premium screen and tap Restore Purchases. ### Disclaimer FinalTurn is an independent companion app for trading card game players.
